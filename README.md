# UI Engine Sample App

Welcome to the **UI Engine Sample App**! This repository serves as a live demonstration and reference implementation for integrating and using the [UI-Engine](https://github.com/rajbirsehmi/UI-Engine) library in a modern Jetpack Compose application.

## 🚀 Purpose

The goal of this sample app is to showcase how to build robust, maintainable, and flake-free UI tests using the UI-Engine framework.

## 🛠 Features Showcased (Not implemented yet)

The following categories are planned to showcase UI-Engine's capabilities:

- **Action Components**
- **Text & Input Controls**
- **Containment & Structure**
- **Navigation Components**
- **Communication & Feedback**
- **Layout Containers**

## 🏗 Built With

- **[Jetpack Compose](https://developer.android.com/jetpack/compose):** Modern toolkit for building native UI.
- **[UI-Engine](https://github.com/rajbirsehmi/UI-Engine):** Industrial-grade testing framework for Compose.

## 📥 Getting Started

### 1. Clone the Repository
```bash
git clone https://github.com/rajbirsehmi/UI-Engine-Sample-App.git
```

### 2. Run the App
Open the project in Android Studio and run the `app` module on an emulator or physical device.
